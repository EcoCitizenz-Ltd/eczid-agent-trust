# Contributing

This is an official ECZ-ID public product/documentation repository.

Documentation corrections, reproducible product issues, and practical examples are welcome.

Keep claims evidence-accurate. Do not describe ECZ-ID, an MCP server, an AI agent, an API, supplier, or machine as certified safe, approved, guaranteed secure, or compliant unless an authoritative cited source specifically supports that claim.

Never commit secrets, private keys, customer confidential information, or private evidence.
